- Получила **accuracy 91,48%** в отдельном валидационном эксперименте на Fashion Product Images (33 класса, 6 083 изображения).

**Стек:** React, JavaScript, Python, Flask, MySQL, SQLAlchemy, PyTorch, ONNX Runtime, REST API.
